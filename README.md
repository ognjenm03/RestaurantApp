# Laravel Project

This is a Laravel application that can be run locally using XAMPP.  

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/username/project-name.git
   cd project-name
   Start Apache and MySQL in the XAMPP Control Panel.

Run the restart.bat script located in the project folder.
This script will:

-Create the database
-Run all migrations
-Seed the database

In your terminal, start the Laravel development server:

php artisan serve

The application will be available at:

http://127.0.0.1:8000
